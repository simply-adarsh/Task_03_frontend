# ✦ CSS Layout Lab

A responsive, interactive frontend experiment built with **HTML and CSS**.

Explore three essential CSS concepts in one polished page:

- 📌 **Sidebar Layout** — Flexbox with responsive navigation
- 📦 **Box Model Card** — Toggle margin, border, padding, and content layers
- 📰 **Three-Column Blog** — Flexible columns that stack on mobile

## ✨ Features

- Responsive design for desktop and mobile
- Light and dark mode support
- Interactive box-model visualization
- Flexbox-based layouts
- Expandable CSS code examples
- Modern typography and clean UI
- No frameworks or JavaScript required

## 🚀 Run locally

Open `fontendlabtask3.html` directly in your browser, or use VS Code Live Server.

## 🧠 Concepts demonstrated

```css
display: flex;
flex: 1 1 auto;
flex: 1 1 0;
box-sizing: border-box;
@media (max-width: 700px);
```

## 🌐 Responsive breakpoints

| Breakpoint | Behavior |
|---|---|
| Below `700px` | Blog columns stack vertically |
| Below `560px` | Sidebar becomes a horizontal navigation strip |
