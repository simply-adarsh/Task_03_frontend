01

Sidebar layout

A fixed-width sidebar and a fluid main area, side by side with Flexbox. Under 560px the sidebar flattens into a horizontal strip so it doesn't eat the screen.

Overview

This is the main content area. It grows to fill whatever space the sidebar doesn't take, using flex: 1 1 auto.

resize below 560px wide to see the sidebar flatten

view CSS 
/* container */
.sidebar-demo { display: flex; }

/* fixed-width sidebar, doesn't shrink */
.side { flex: 0 0 160px; }

/* main area takes remaining space */
.main { flex: 1 1 auto; }

/* stack on small screens */
@media (max-width: 560px) {
  .sidebar-demo { flex-direction: column; }
  .side { flex: 0 0 auto; display: flex; }
}
